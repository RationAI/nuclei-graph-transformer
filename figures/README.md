## Input normalization

The dataset patch is a uint8 RGB tensor; the model normalizes it in `Transformer.embed_patches` as `x / 127.5 - 1` (to [-1, 1]). For display that normalization is undone (`(x + 1) * 127.5`), which gives back the uint8 patch exactly. No other normalization (e.g. ImageNet mean/std, stain normalization) is applied to the input.
